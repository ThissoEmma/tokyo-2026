# Tokyo, November 2026

一个面向手机浏览的东京五日旅行静态网页。

## 本地预览

直接打开 `index.html`，或在本目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## GitHub Pages

仓库推送至 GitHub 后，在仓库的 **Settings → Pages** 中选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

保存后等待 GitHub 完成部署。
